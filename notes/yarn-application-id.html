YARN Application ID

정리 2026-06-26

한 줄 정의

YARN에서 실행 중인 Spark, MapReduce 같은 작업 하나를 식별하는 고유 ID.

자세히

yarn application -list를 실행하면 첫 번째 컬럼에 application_... 형식의 값이 나온다. yarn application -kill은 이 값을 받아서 해당 작업을 종료한다.

잘못된 예:

yarn application -kill yarn

올바른 예:

yarn application -kill application_1718000000000_1234

왜 중요/어디서 씀

장시간 Spark 작업이 잘못 떠 있거나 리소스를 계속 잡고 있을 때 정확한 application만 종료해야 한다. 잘못된 문자열을 넣으면 Invalid ApplicationId prefix 오류가 난다.

예시

yarn application -list -appStates RUNNING
yarn application -kill application_1718000000000_1234
