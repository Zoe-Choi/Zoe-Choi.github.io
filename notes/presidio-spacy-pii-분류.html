Presidio spaCy PII 분류

정리 2026-07-16

한 줄 정의

OpenMetadata의 PII 자동 분류는 Presidio(판정 총괄) + spaCy(NLP 엔진) + en_core_web_md(학습된 모델)의 3층 구조로 동작한다.

자세히

  • spaCy: NLP 라이브러리(엔진). tokenize, POS tagging, NER 제공. 자체는 빈 엔진이라 모델을 로드해야 동작.
  • en_core_web_md: spaCy가 로드하는 사전 학습 영어 모델(약 40MB). 이름 분해 en(영어) + core(기본 기능) + web(웹 학습) + md(medium, word vector 포함). PERSON/LOCATION 등 실제 개체 판정을 수행. 다운로드 대상이 이 파일.
  • Presidio: Microsoft 오픈소스 PII 탐지/마스킹 프레임워크. recognizer 조합으로 판정.
    • 정규식 recognizer: email, credit card, 전화번호, 주민번호 등 패턴 고정 항목 (+ checksum)
    • NLP recognizer: 이름/지명 등 패턴 없는 항목 -> spaCy + en_core_web_md 호출

흐름: 컬럼 샘플링 -> Presidio 분석(정규식 + spaCy NLP) -> PII 종류 판정 -> OM 태그(PII.Sensitive/PII.NonSensitive) 매핑 -> 컬럼 태그 부착.

왜 중요/어디서 씀

OpenMetadata AutoClassification 에이전트가 이 스택을 사용. en_core_web_md만 없어도 NLP 계열 탐지 불가. 사내망처럼 외부 차단 환경에서는 모델 다운로드가 timeout 나며 파이프라인 전체 실패. 해결은 모델 오프라인 설치(Nexus PyPI 또는 .whl 수동 설치 후 컨테이너 재기동).

예시

  • 비유: spaCy = 드릴 본체, en_core_web_md = 드릴 비트(없으면 못 뚫음), Presidio = 작업 지시자.
  • 오프라인 설치: pip install en-core-web-md --index-url <사내 Nexus PyPI> 또는 .whl 복사 후 pip install <file>.whl.
